# APUNTES PHP

PHP admite los siguientes tipos de datos:

cadena (valores de texto)
entero (números enteros)
flotante (números decimales)
booleano (verdadero o falso)
matriz (múltiples valores)
objeto (almacena datos como objetos)
nulo (variable vacía)
recurso (hace referencia a recursos externos)
